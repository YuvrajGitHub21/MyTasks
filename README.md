# MyTasks

A cross-platform task planning app, designed for guest use first and account sync later.

## Project layout

- [`Documentation/`](Documentation/README.md) — requirements, architecture, detailed design, UI preview, and implementation plan.
- [`frontend/`](frontend/README.md) — Flutter Android/iOS application.
- [`backend/`](backend/README.md) — Java 25 / Spring Boot API and worker.
- `infrastructure/` — to be added when development cloud resources are ready to be managed as code.

## Current status

The HLD and LLD technology direction is approved, and the current UI preview is approved as the visual baseline. Next is to finish M0 product/UX readiness, then establish the reproducible M1 repository and build foundation. See [`Documentation/Implementation-Plan.md`](Documentation/Implementation-Plan.md).
